# GYMLOG

A React, TypeScript, and Vite workout tracking app.

## Development

```sh
npm ci
npm run dev
```

## GitHub Pages deployment

The site is built and deployed automatically by GitHub Actions whenever a commit is pushed or merged into `main`. The workflow can also be run manually from the repository's **Actions** tab.

For the first deployment, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.

The production site is available at <https://affandraa.github.io/GYMLOG/>.
